A small deterministic program that writes a single museum-placard line for an ordinary office object treated as an ancient artifact: a whiteboard marker, catalogued as an oracle of the brainstorming rite whose final prophecy — ‘SYNERGY’ — went unfulfilled. It composes the line from named catalogue parts (object, date, material, conceit, donor), checks it fits the 1–180 character gate, and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
